About

Senior Solution Engineer IBS Software

I like the part of the job most people skip: staying with the code after it goes live.

I build and maintain enterprise applications end to end — taking a requirement from the business, designing it, writing the Java and the JavaScript, testing it, releasing it, and then supporting it in production for real customers.

A lot of my work is diagnosis. A client reports something broken, and I trace it through the application and server logs, separate a genuine defect from expected behaviour, find the root cause, and ship a permanent fix rather than a patch over the symptom. I have done that across development, UAT and production environments.

I work in Agile Scrum with remote and onsite teams, write things down so the next person does not have to rediscover them, and use AI-assisted tooling daily — validating every suggestion before it reaches a commit.
